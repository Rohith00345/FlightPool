## 3. Security Invariants
1. **No In-Memory Secret Storage**: Secrets (`JWT_SECRET`, `CRON_SECRET`, `RAZORPAY_WEBHOOK_SECRET`) are loaded from environment variables and never logged or exposed in client bundles.
2. **Timing Attack Immunity**: Webhook signature verification uses `crypto.timingSafeEqual`.
3. **Cross-User Protection (IDOR)**: Database lookups verify `session.userId === target.userId` for every mutating endpoint (`/api/rides/request`, `/api/pools/solo`, `/api/pools/[id]/consent-pricing`, `/api/incidents`, `/api/user/delete-data`).
4. **Denial by Default**: All sensitive APIs reject missing authentication headers with `401 Unauthorized` and unprivileged roles with `403 Forbidden`.
